# Contribution Guide for Toronto JS' Community Hub

Thank you for your interest in contributing to the project. This guide contains all you need to setup and make changes to it.

## Assumptions

We assume you have a basic knowledge of web development and `git`. But if you need help setting up, please contact one of the contributors so we can help getting things running.
