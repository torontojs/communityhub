# Community Hub Permissions per Role

Here is the list of permissions each role had for each action inside the platform.

## Profile

| Action                         | Admin | Organizer | Volunteer | Public |
| ------------------------------ | :---: | :-------: | :-------: | :----: |
| Sign-up (create a new profile) |  ✅   |    ✅     |    ✅     |   ❌   |
| Sign-in                        |  ✅   |    ✅     |    ✅     |   ❌   |
| Sign-out                       |  ✅   |    ✅     |    ✅     |   ❌   |
| Reset password                 |  ✅   |    ✅     |    ✅     |   ❌   |
| Edit own profile (minus email) |  ✅   |    ✅     |    ✅     |   ❌   |
| Edit other profile             |  ✅   |    ❌     |    ❌     |   ❌   |
| Delete profile                 |  ✅   |    ❌     |    ❌     |   ❌   |
| View profile                   |  ✅   |    ✅     |    ✅     |   ✅   |
| List profiles                  |  ✅   |    ✅     |    ✅     |   ✅   |

## Documents

| Action                      | Admin | Organizer | Volunteer | Public |
| --------------------------- | :---: | :-------: | :-------: | :----: |
| Sign documents              |  ✅   |    ✅     |    ✅     |   ❌   |
| View own documents          |  ✅   |    ✅     |    ✅     |   ❌   |
| View other signed documents |  ✅   |    ✅     |    ❌     |   ❌   |

## Team/Projects/Events

| Action                | Admin | Organizer | Volunteer | Public |
| --------------------- | :---: | :-------: | :-------: | :----: |
| Create                |  ✅   |    ✅     |    ❌     |   ❌   |
| Edit                  |  ✅   |    ✅     |    ❌     |   ❌   |
| Delete (they created) |  ✅   |    ✅     |    ❌     |   ❌   |
| Delete (others)       |  ✅   |    ❌     |    ❌     |   ❌   |
| View                  |  ✅   |    ✅     |    ✅     |   ✅   |
| List                  |  ✅   |    ✅     |    ✅     |   ✅   |
